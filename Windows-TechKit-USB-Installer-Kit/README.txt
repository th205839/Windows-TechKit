Windows-TechKit USB Support Kit
===============================

Kit tecnico de suporte para pendrive.

Funcionalidades:
- Instalar Windows
- Abrir toolkit de suporte
- Diagnostico basico
- Ferramentas de manutencao

Como usar:
1. Copie esta pasta para o pendrive.
2. Execute Menu-USB.cmd.
3. Escolha a opcao desejada.
