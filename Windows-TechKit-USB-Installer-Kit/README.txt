Windows-TechKit USB Installer Kit
===============================

Kit tecnico para pendrive com ferramentas de diagnostico, reparo, backup e instalacao do Windows 10/11.

Conteudo:
- Ferramentas do Windows-TechKit
- Scripts de inicializacao
- Pasta para ISOs do Windows 10/11
- Guia tecnico em portugues

Como usar:
1. Copie esta pasta para o pendrive.
2. Coloque a ISO do Windows 10 ou 11 na pasta isos/.
3. Execute Start.bat ou Start.cmd na raiz do pendrive.
4. Use as ferramentas para diagnostico, reparo, backup e relatorios.
