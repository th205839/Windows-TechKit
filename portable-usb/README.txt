Windows-TechKit USB Installer Kit
================================

This folder is intended to be copied to a bootable USB drive.
It includes:
- Windows-TechKit tools and scripts
- Driver and backup folders
- Installation resources for Windows 10 and Windows 11
- A bootstrap script to prepare the USB for technician use

How to use:
1. Copy this folder to a USB drive.
2. Run Prepare-USB.ps1 from PowerShell as Administrator.
3. Use the USB as a technician recovery and deployment tool.

Note:
This package does not contain Windows ISO files by default. You should add your own licensed Windows 10/11 ISO images to the isos/ folder if needed.
