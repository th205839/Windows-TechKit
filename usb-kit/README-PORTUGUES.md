# Windows-TechKit USB Kit

Este pacote foi organizado para ser usado em um pendrive e ajudar na instalação, recuperação e manutenção do Windows 10/11.

## O que vem no pendrive
- Ferramentas do Windows-TechKit
- Scripts para iniciar o toolkit
- Pasta para ISOs do Windows 10/11
- Guia de uso para técnico

## Como usar
1. Copie a pasta usb-kit para o pendrive.
2. Coloque a ISO do Windows 10 ou 11 na pasta isos/.
3. No PowerShell, execute:

```powershell
./scripts/Menu-USB.ps1
```

## Funções disponíveis
- Diagnóstico de hardware e rede
- Reparos e manutenção
- Backup e restauração de drivers
- Relatórios e logs
- Suporte para instalação do Windows 10/11

## Observação
Use com privilégios administrativos em computadores Windows.
